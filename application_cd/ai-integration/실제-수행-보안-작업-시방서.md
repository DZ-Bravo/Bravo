# Prometheus 보안 설정 - 실제 수행 작업 시방서

## 1. Kubernetes RBAC 설정 (실제 생성된 리소스)

| Namespace | ServiceAccount | Role Name | Role / ClusterRole | Resources | verbs | Description |
|-----------|----------------|-----------|-------------------|-----------|-------|-------------|
| bravo-monitoring-ns | prometheus-scraper | prometheus-scraper | ClusterRole | nodes | get, list, watch | 노드 정보 조회 |
| bravo-monitoring-ns | prometheus-scraper | prometheus-scraper | ClusterRole | nodes/metrics | get, list, watch | 노드 메트릭 조회 |
| bravo-monitoring-ns | prometheus-scraper | prometheus-scraper | ClusterRole | nodes/proxy | get, list, watch | 노드 프록시를 통한 cAdvisor 메트릭 접근 |
| bravo-monitoring-ns | prometheus-scraper | prometheus-scraper | ClusterRole | pods | get, list, watch | 파드 정보 조회 |

**생성 명령어:**
```bash
kubectl create serviceaccount prometheus-scraper -n bravo-monitoring-ns
kubectl create clusterrole prometheus-scraper --verb=get,list,watch --resource=nodes,nodes/metrics,nodes/proxy,pods
kubectl create clusterrolebinding prometheus-scraper --clusterrole=prometheus-scraper --serviceaccount=bravo-monitoring-ns:prometheus-scraper
```

**보안 특징:**
- 최소 권한 원칙: 필요한 리소스만 접근 허용
- 읽기 전용 권한: 수정 불가 (create, update, delete 없음)
- 클러스터 레벨 권한: 모든 네임스페이스의 노드와 파드 접근 가능

## 2. 토큰 생성 및 관리 (실제 수행 작업)

| 항목 | 설정 값 | 설명 |
|------|---------|------|
| 토큰 생성 위치 | 로컬 환경 | kubectl이 정상 작동하는 환경 |
| 토큰 생성 명령어 | `kubectl create token prometheus-scraper -n bravo-monitoring-ns --duration=8760h` | ServiceAccount 토큰 생성 |
| 토큰 형식 | JWT (JSON Web Token) | 표준 인증 토큰 형식 |
| 토큰 유효기간 | 8760시간 (1년) | 생성 시 설정 |
| 토큰 저장 위치 | /tmp/prometheus-k8s-token (EC2) | 모니터링 EC2에 저장 |
| 파일 권한 설정 | 600 | `chmod 600 /tmp/prometheus-k8s-token` |
| 파일 소유자 | ssm-user (EC2) | EC2 접속 사용자 |

**수행 작업:**
1. 로컬에서 토큰 생성
2. 토큰 내용을 EC2에 수동 복사
3. 파일 권한 600으로 설정

## 5. 보안 설정 상세

### 5.1 ServiceAccount 보안 설정
- **네임스페이스 격리**: `bravo-monitoring-ns`에만 존재
- **자동 토큰 생성**: Kubernetes가 자동으로 Secret 생성
- **토큰 자동 갱신**: 만료 시 자동 갱신 가능

### 5.2 ClusterRole 보안 설정
- **허용된 리소스**:
  - `nodes`: 노드 정보 조회
  - `nodes/metrics`: 노드 메트릭 조회
  - `nodes/proxy`: 노드 프록시를 통한 cAdvisor 메트릭 접근
  - `pods`: 파드 정보 조회
- **허용된 동작**: `get`, `list`, `watch` (읽기 전용)
- **제한된 리소스**: `secrets`, `configmaps`, `deployments`, `services` 등 접근 불가
- **제한된 동작**: `create`, `update`, `delete` 모든 리소스에 대해 불가

### 5.3 토큰 파일 보안 설정
- **파일 권한**: 600 (소유자만 읽기/쓰기)
- **저장 위치**: `/tmp/prometheus-k8s-token` (임시 디렉토리)
- **보안 조치**: 
  - 다른 사용자 접근 차단
  - 로그에 토큰 내용 남기지 않음

## 6. 확인 명령어

| 확인 항목 | 명령어 | 예상 결과 |
|-----------|--------|-----------|
| ServiceAccount 확인 | `kubectl get sa prometheus-scraper -n bravo-monitoring-ns` | prometheus-scraper 존재 확인 |
| ClusterRole 확인 | `kubectl get clusterrole prometheus-scraper` | prometheus-scraper 존재 확인 |
| ClusterRoleBinding 확인 | `kubectl get clusterrolebinding prometheus-scraper` | prometheus-scraper 존재 확인 |
| 권한 상세 확인 | `kubectl describe clusterrole prometheus-scraper` | nodes, nodes/metrics, nodes/proxy, pods 권한 확인 |
| ConfigMap 확인 | `kubectl get configmap prometheus-config -n bravo-monitoring-ns` | prometheus-config 존재 확인 |
| 토큰 파일 확인 (EC2) | `ls -l /tmp/prometheus-k8s-token` | 권한 600 확인 |
