# Prometheus 보안 설정 시방서

## 1. Kubernetes RBAC 설정

| Namespace | ServiceAccount | Role Name | Role / ClusterRole | Resources | verbs | Description |
|-----------|----------------|-----------|-------------------|-----------|-------|-------------|
| bravo-monitoring-ns | prometheus-scraper | prometheus-scraper | ClusterRole | nodes | get, list, watch | 노드 정보 조회 |
| bravo-monitoring-ns | prometheus-scraper | prometheus-scraper | ClusterRole | nodes/metrics | get, list, watch | 노드 메트릭 조회 |
| bravo-monitoring-ns | prometheus-scraper | prometheus-scraper | ClusterRole | nodes/proxy | get, list, watch | 노드 프록시를 통한 cAdvisor 메트릭 접근 |
| bravo-monitoring-ns | prometheus-scraper | prometheus-scraper | ClusterRole | pods | get, list, watch | 파드 정보 조회 |

**제한된 리소스:**
- `secrets`, `configmaps`: 읽기 불가 (민감 정보 보호)
- `deployments`, `services`: 읽기 불가 (불필요)
- 모든 리소스에 대한 `create`, `update`, `delete` 권한 없음

## 2. 네트워크 보안 설정

| NS | Policy Name | Target Pod (app) | Allowed From | Direction | Protocol | Port | Description |
|----|-------------|------------------|--------------|-----------|----------|------|-------------|
| bravo-monitoring-ns | prometheus-k8s-access | prometheus | Kubernetes API Server | Egress | HTTPS | 443 | Kubernetes API 서버를 통한 메트릭 수집 |
| bravo-monitoring-ns | prometheus-k8s-access | prometheus | Node 1 (10.0.17.71) | Egress | HTTPS | 443 | 노드 1 cAdvisor 메트릭 수집 (API 서버 경유) |
| bravo-monitoring-ns | prometheus-k8s-access | prometheus | Node 2 (10.0.24.98) | Egress | HTTPS | 443 | 노드 2 cAdvisor 메트릭 수집 (API 서버 경유) |

**보안 특징:**
- 직접 노드 접근 차단 (10.0.17.71:10250, 10.0.24.98:10250 직접 접근 불가)
- Kubernetes API 서버를 통한 간접 접근만 허용
- Bearer Token 인증 필수

## 3. 토큰 관리 보안

| 항목 | 설정 값 | 설명 |
|------|---------|------|
| 토큰 형식 | JWT (JSON Web Token) | 표준 인증 토큰 형식 |
| 토큰 생성 방법 | ServiceAccount 토큰 | Kubernetes ServiceAccount 기반 |
| 토큰 유효기간 | 8760시간 (1년) | 필요시 조정 가능 |
| 토큰 저장 위치 | /tmp/prometheus-k8s-token (EC2) | 임시 디렉토리 사용 |
| 파일 권한 | 600 | 소유자만 읽기/쓰기 가능 |
| 토큰 갱신 | 수동 재생성 | 만료 시 새 토큰 생성 필요 |

**보안 조치:**
- 파일 권한 600으로 다른 사용자 접근 차단
- 토큰 내용을 로그에 남기지 않음
- 정기적인 토큰 갱신 권장

## 4. Security Group 설정 (EC2)

| VPC NAME | Security Group Name | 적용 대상 | Inbound Rules | Outbound Rules | 설명 |
|----------|---------------------|-----------|---------------|----------------|------|
| bravo-vpc | bravo-monitoring-sg | Monitoring EC2 (10.0.0.40) | TCP 9090 (Prometheus) : 내부 VPC 대역 (192.168.0.0/22)<br>TCP 3000 (Grafana) : 내부 VPC 대역 (192.168.0.0/22)<br>TCP 3100 (Loki) : 내부 VPC 대역 (192.168.0.0/22)<br>TCP 22 (SSH) : 관리자 접근용 내부 대역 (192.168.0.0/22) | ALL (기본 허용) | Prometheus, Grafana, Loki 등 모니터링 시스템 운영을 위한 보안 그룹 |

**추가 보안 규칙:**
- Prometheus (9090): 내부 VPC에서만 접근 가능
- Grafana (3000): 내부 VPC에서만 접근 가능
- Loki (3100): 내부 VPC에서만 접근 가능
- SSH (22): 관리자 접근용 내부 대역만 허용

## 6. 보안 체크리스트

| 항목 | 상태 | 비고 |
|------|------|------|
| ServiceAccount 생성 및 사용 | ✅ 완료 | prometheus-scraper (bravo-monitoring-ns) |
| ClusterRole로 최소 권한 부여 | ✅ 완료 | nodes, nodes/metrics, nodes/proxy, pods (읽기 전용) |
| 토큰 기반 인증 구현 | ✅ 완료 | JWT 형식 ServiceAccount 토큰 |
| HTTPS 통신 사용 | ✅ 완료 | Kubernetes API 서버 통한 접근 |
| 파일 권한 설정 (600) | ✅ 완료 | /tmp/prometheus-k8s-token |
| 네임스페이스 격리 | ✅ 완료 | bravo-monitoring-ns |
| 인증서 검증 활성화 | ⚠️ 개선 필요 | 현재 insecure_skip_verify: true (내부 네트워크용) |
| 토큰 만료 시간 단축 | ⚠️ 개선 필요 | 현재 1년 → 30일 권장 |
| 정기적 토큰 갱신 자동화 | ⚠️ 미구현 | 수동 갱신 필요 |
| 접근 로그 모니터링 | ⚠️ 미구현 | Prometheus 접근 로그 확인 필요 |

## 9. 확인 명령어

| 확인 항목 | 명령어 |
|-----------|--------|
| ServiceAccount 확인 | `kubectl get sa prometheus-scraper -n bravo-monitoring-ns` |
| ClusterRole 확인 | `kubectl get clusterrole prometheus-scraper` |
| ClusterRoleBinding 확인 | `kubectl get clusterrolebinding prometheus-scraper` |
| 토큰 파일 확인 (EC2) | `ls -l /tmp/prometheus-k8s-token` |
| 권한 상세 확인 | `kubectl describe clusterrole prometheus-scraper` |
